连接设备（BLE）

设备开机即进入 TIME SYNC 同步页（若在表盘页：长按 OK → 菜单选 3 TIME SYNC）， 蓝牙自动广播，点击连接即可。屏幕显示 BT: ADVERTISING=可连接、BT: LINKED=已连接。

连接须知（同步后设备行为 / 再同步方法）
蓝牙仅在时间同步页开启，表盘页不耗蓝牙电。
同步成功后设备停留在同步页并持续显示最新状态（连接保持，可继续查看下方"设备状态"）； 在设备上按 OK 键进入表盘时蓝牙随之关闭（正常现象，不是故障）。
需要再次同步：设备上长按 OK 键 → 3 TIME SYNC 回到同步页，蓝牙自动重开。
Mac / 浏览器搜不到设备？排查步骤
最省事：直接用顶部"USB 线同步"标签页（插线即可，不依赖蓝牙）。想继续走蓝牙，按顺序排查：
① 确认安卓手机已断开连接（BLE 同一时间只允许一个中心设备连接，被占用时设备不广播）； 且设备同步页屏幕显示 BT: ADVERTISING（表盘页无蓝牙，长按 OK → 3 TIME SYNC 进入同步页）；
② 保持上方"仅显示名称过滤"不勾选——从全部设备列表里找。名字不是 CyberClock 的陌生设备也可能是它（macOS 会缓存旧的蓝牙广播名）；
③ 系统设置 → 隐私与安全性 → 蓝牙：确认 Chrome 已被允许（首次弹窗点过"不允许"会静默失败）；
④ 地址栏输入 chrome://bluetooth-internals → Devices → Start Scan：这里能扫到设备说明是选择器问题，扫不到则是系统蓝牙层面问题；
⑤ 系统设置 → 蓝牙 → 关闭再重新打开，重试；还不行就重启 Mac；
⑥ 都不行就改用 USB 线同步（见顶部标签页）或包内 mac-sync.py 脚本。

连接设备（USB Serial）

用刷固件的 同一条 USB 数据线连接设备，点击"连接 USB 设备"， 选 USB 串行设备（VID 303A） 即可，全程不碰蓝牙。

常见问题（驱动 / 烧录互斥 / 列表为空）
固件要求 v5 及以上（v4 及更早没有 USB 对时命令，PING 无响应时请先升级固件）。
浏览器占用串口期间 无法烧录固件（esptool 打不开端口），烧录前先点"断开"。
打开串口瞬间设备可能复位一次，属正常现象，页面会自动重试 PING。
Windows 弹窗为空：本设备是 ESP32-C3 原生 USB（Win10/11 免驱），列表为空多为线是充电线； 其他板子才需要 CP210x 驱动。
