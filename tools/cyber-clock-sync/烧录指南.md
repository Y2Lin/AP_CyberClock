# 赛博朋克时钟固件 · 烧录指南

基于 [folotoy/ai-passport](https://github.com/folotoy/ai-passport) 构建的赛博朋克时钟固件，适用于 **FoloToy AI Passport**（ESP32-C3，8MB Flash）。

---

## 包内文件

| 文件 | 说明 |
|---|---|
| `firmware/FoloToy-AI-Passport-full.bin` | **合并固件（推荐）**，含 bootloader + 分区表 + 应用，刷入地址 `0x0` |
| `firmware/bootloader.bin` | 分段刷录用 bootloader，地址 `0x0` |
| `firmware/partition-table.bin` | 分段刷录用分区表，地址 `0x8000` |
| `firmware/FoloToy-AI-Passport.bin` | 分段刷录用应用固件，地址 `0x10000` |
| `index.html` | **时间同步页（BLE + USB 双通道）**：蓝牙标签页走 Web Bluetooth；USB 标签页用刷机线直接对时（Web Serial，Mac 免蓝牙，Chrome/Edge 打开） |
| `mac-sync.py` | **命令行 BLE 同步脚本**（Chrome 搜不到设备时用，走系统蓝牙，`pip3 install bleak` 后运行） |
| `usb-sync.py` | **命令行 USB 同步脚本**（`pip3 install pyserial` 后运行，Mac/Windows/Linux 通用，v5 固件） |
| `时钟功能与BLE同步说明.md` | 时钟功能、按键操作、手机/Mac BLE 与 USB 时间同步方法 |
| `构建信息.md` | 构建环境、固件校验与 SHA256 |

## 烧录方式一：网页刷机（推荐，最简单）

### 准备
- 一根**支持数据传输**的 USB 线（纯充电线不行）
- 桌面版 **Chrome 或 Edge** 浏览器（版本 ≥ 89，不支持 Safari / Firefox / 手机浏览器）

### 步骤
1. 用 USB 线将 AI Passport 连接到电脑
2. 打开官方刷机页（二选一）：
   - FoloToy 官方：`https://ai-passport.folotoy.cn/tools/web-flasher/`（首选，厂商出品）
   - Espressif 官方：`https://espressif.github.io/esptool-js/`（芯片厂商通用版）
3. 点击 **连接设备**，在系统弹窗中选择名称含 **`USB JTAG/serial debug unit`** 的串口
   - Windows：`USB JTAG/serial debug unit (COMxx)`
   - macOS：`USB JTAG/serial debug unit (cu.usbmodem…)`
   - 不要选择蓝牙、SPP、耳机类端口
4. 选择**合并固件** `firmware/FoloToy-AI-Passport-full.bin`，烧录地址保持 `0x0`
   - 固件在线直链（esptool-js 页面可直接粘贴）：`https://y2lin.github.io/AP_CyberClock/firmware/FoloToy-AI-Passport-full.bin`
5. 波特率保持默认 `115200`（线材质量好可提速到 `460800`；**一旦报错先降回 115200**）
6. 点击写入，等待进度条走完，设备自动重启

### 刷机页"清除设备数据"选项说明
- 不勾选 = 保留设备上的用户数据（NVS 中的卡号、配对信息等）
- 勾选 = 整片擦除，恢复干净状态。仅在设备异常、需要恢复出厂时使用

## 烧录方式二：命令行（esptool / idf.py）

已安装 ESP-IDF v5.5.3 环境的用户：

```bash
idf.py flash monitor    # 增量刷写应用（保留 bootloader/分区表）
```

或使用 esptool 分段刷写（三种 .bin 均在 `firmware/` 目录）：

```bash
esptool.py --chip esp32c3 --baud 460800 write_flash \
  0x0 bootloader.bin \
  0x8000 partition-table.bin \
  0x10000 FoloToy-AI-Passport.bin
```

## 重要注意事项

1. **分区保护**：本固件沿用官方 8MB 分区表，`cardid@0x356000` 与 `recovery@0x700000` 两个分区受小程序 BLE 安装通道保护，合并固件中这两处为空填充（0xFF），刷入不会破坏设备身份与恢复程序。
2. **刷合并固件 vs 分段固件**：
   - 设备为**全新/空白 flash** → 优先刷合并固件（`0x0`）
   - 设备上已有官方固件，只想**更新应用** → 可只刷 `FoloToy-AI-Passport.bin`（`0x10000`）
3. **刷写过程中不要拔线或断电**，否则可能导致设备无法启动（重新完整刷写即可恢复）。
4. **烧录前先断开网页同步页的 USB 连接**：`index.html` 的 USB 标签页占用的就是刷机串口，占线时 esptool / 刷机页都打不开端口。
5. **恢复模式**：如设备刷完不启动，按住 **UP 键**再复位，可进入永久 Recovery（bootloader 内置 5 秒 UP 手势钩子），或直接重新刷写合并固件。
6. 本固件与 AI Passport 硬件绑定，请勿刷入其他型号设备。

## 烧录后首次使用

1. 开机直进 **TIME SYNC 时间同步页**（v8 动线：同步页 → 表盘 → 菜单）
2. 对时三选一（同步页蓝牙已自动开广播）：
   - **USB 线（最简单）**：`index.html` → "USB 线同步"标签页 → 连接 → 自动写入（v5 起，任意页面可用）
   - **手机蓝牙**：nRF Connect / LightBlue 连接 `CyberClock` 写入时间戳
   - **Mac 蓝牙**：`index.html` 蓝牙标签页或 `mac-sync.py` 脚本
3. **蓝牙动线（v8 起）**：蓝牙仅在时间同步页开启（开机首屏自动广播，屏幕中央 `BT: ADVERTISING`）；
   **同步成功约 5 秒后自动进入表盘并关闭蓝牙**（正常现象），再同步：长按 **OK 键** → 菜单选 **3 TIME SYNC**
4. 详细操作、协议与故障排除见 `时钟功能与BLE同步说明.md`

## 故障排除

| 现象 | 处理方法 |
|---|---|
| 弹窗里没有串口 | 换数据线；直连主机 USB 口，勿用扩展坞；确认设备已上电 |
| 一直停在 Connecting | 按住 BOOT 点按 RST 进下载模式后重试；确认选的是 `USB JTAG/serial debug unit` |
| 刷写中途失败 | 波特率降到 115200；换短线、USB 2.0 口；确认 `index.html` USB 标签页已断开（同一条串口不能两头占用） |
| 浏览器提示不支持 | 改用桌面版 Chrome / Edge |
| 刷完不启动 | 重新刷写合并固件；必要时勾选"清除设备数据"后重刷 |
| 时钟显示 1970 | 未同步时间，USB / BLE 任一方式同步一次即可（详见功能说明） |
| 同步成功后手机/App 提示蓝牙断开 | v8 动线的正常行为：同步约 5 秒后设备自动进表盘并关蓝牙；再同步：设备长按 OK → 3 TIME SYNC |
| USB 对时无响应（PING 不回 PONG） | 固件低于 v5，刷入本包固件后重试（详见功能说明"USB 时间同步"章节） |
| 连接时"配对失败" | 手机端先"忽略"旧的设备绑定，再用 nRF Connect/LightBlue 连接（勿走系统蓝牙设置）；本固件已支持自动重新配对，详见功能说明的"配对说明"章节 |
| Mac Chrome 搜不到设备 | 最省事：改用 `index.html` 的 **USB 标签页**（插线即用）；坚持走蓝牙则按功能说明"Mac 同步步骤"排查，或用 `mac-sync.py` 脚本绕过 Chrome |
