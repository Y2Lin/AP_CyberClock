连接设备（BLE）

先在设备上进入 CyberClock 页面，再点击连接。设备蓝牙状态看屏幕右上角： BT ADV=广播中（可直接连）、BT LINK=已连接、BT OFF=已关闭。
v6 省电策略：设备时间未同步时进入时钟页会自动开广播；已同步则默认关闭蓝牙省电 ——此时要在设备上短按 OK 键打开蓝牙（屏幕变为 BT ADV）再连接。
同步成功约 5 秒后设备会自动断开并关闭蓝牙（正常现象，不是故障）；需要再同步就按 OK 键重新打开。
Mac 找不到设备？最省事的办法：直接改用顶部“USB 线同步”标签页（插线即可，不依赖蓝牙）。
想继续走蓝牙，先做交叉验证（金标准）：Mac 设备选择框保持打开的同时，用安卓 nRF Connect 只扫描不连接——手机此刻能看到 CyberClock 而 Mac 看不到，说明设备广播正常、问题在 Mac 侧。然后按顺序排查：
① 确认安卓手机已断开连接（BLE 同一时间只允许一个中心设备连接，被占用时设备不广播）； 且设备屏幕显示 BT ADV（BT OFF 时按 OK 键打开）；
② 保持上方"仅显示名称过滤"不勾选——从全部设备列表里找。名字不是 CyberClock 的陌生设备也可能是它（macOS 会缓存旧的蓝牙广播名）；
③ 系统设置 → 隐私与安全性 → 蓝牙：确认 Chrome 已被允许（首次弹窗点过"不允许"会静默失败）；
④ 地址栏输入 chrome://bluetooth-internals → Devices → Start Scan：这里能扫到设备说明是选择器问题，扫不到则是系统蓝牙层面问题；
⑤ 系统设置 → 蓝牙 → 关闭再重新打开，重试；还不行就重启 Mac；
⑥ 都不行就改用 USB 线同步（见顶部标签页）或包内 mac-sync.py 脚本。

连接设备（USB Serial）

用刷固件的 同一条 USB 线连接设备与电脑（必须是数据线），点击"连接 USB 设备"， 在弹窗里选择 USB 串行设备（VID 303A） 即可，全程不碰蓝牙。
固件要求 v5 及以上（v4 及更早没有 USB 对时命令，PING 无响应时请先升级固件）。
浏览器占用串口期间 无法烧录固件（esptool 打不开端口），烧录前先点"断开"。
Windows 若弹窗为空：需要安装 CP210x 驱动 的板子另说；本设备是 ESP32-C3 原生 USB（Win10/11 免驱），列表为空多为线是充电线。
