# 赛博朋克时钟固件设计

适用于固件 v10.1 及以后（commit `2e11cca`）。范围是 AI Passport 板上的 CyberClock 应用栈：`main/`、`cyber_clock.c`、`time_manager.c`、`ble_time_sync.c`、`usb_time_sync.c`。板级事实与 BSP 接口维护在 [../hardware-design/](../hardware-design/README.zh_CN.md)，此处只引用不复制。

## 模块划分

| 模块 | 职责 | 运行位置 |
| --- | --- | --- |
| `main.c` | 启动顺序：I2C → 时间管理 → USB 对时 → 显示/LVGL → 按键；把所有按键事件转发给应用 | `app_main` |
| `cyber_clock.c` | 四页面状态机、表盘 UI 与动效、亮度、按键处理 | LVGL 定时器 + 按键回调 |
| `time_manager.c` | 墙钟归属：设置/读取、时区、同步状态、NVS 持久化 | 被所有任务调用 |
| `ble_time_sync.c` | 可连接 GATT 时间服务（NimBLE 外设），生命周期归同步页所有 | NimBLE host 任务 + esp_timer |
| `usb_time_sync.c` | USB Serial/JTAG 文本协议 `PING` / `T <unix> [tz]` / `Q`，常驻可用 | 独立 `usb_ts` 任务 |

## 并发模型

三个执行上下文共享状态。规则集在 v4 死锁事故后确立：

- **UI 只在 LVGL 定时器上下文执行。** BLE 同步回调与 USB 任务绝不调用 LVGL API；BLE 回调只置 `volatile` 标志，由 100ms 的 `tick()` 定时器消费。
- **按键回调**在 `main.c` 先拿 `bsp_lvgl_lock()` 再进应用，页面切换与渲染持同一把锁。
- **`time_manager` 状态**由 LVGL 上下文按结构体快照读取，写方是 USB 任务或 NimBLE host 任务。ESP32-C3 上单个对齐字段读写是原子的；整快照竞态已知且被接受（最坏一帧状态文字抖动），见"已知限制"。

离开同步页时在持有 LVGL 锁的上下文里同步停掉蓝牙（等 NimBLE host 任务退出）——这是刻意的取舍：接受切页瞬间的一次停顿，换取不需要跨任务拆机状态机。

## 页面状态机

开机落在 `PAGE_SYNC`。四个页面是同一屏幕上互斥的容器；切换即隐藏其余页面，并通过重置"上一秒"标记强制立即刷新。

| 页面 | 进入动作 | 按键 |
| --- | --- | --- |
| 时间同步 | 开启 BLE 广播 | OK：进表盘；长按 OK：菜单 |
| 表盘 | — | UP：切主题；DOWN：完整/精简；长按 OK：菜单 |
| 菜单 | — | UP/DOWN：选择；OK：进入；长按 OK：回表盘 |
| 亮度 | — | UP/DOWN：±10（10..100，即时保存）；OK：返回 |

蓝牙只属于同步页：进页开广播，离页彻底关闭。表盘页完全不碰射频。

## 时间同步数据流

两个入口都汇聚到 `time_manager_set_unix_utc()`：

- **BLE**：写特征 FFC1（小端 uint32 秒，可选第 5-6 字节 int16 时区小时数），订阅方在 FFC2 每 5 秒收到状态通知。
- **USB**：与刷机同一条线上的行式文本协议，任意页面可用，不依赖蓝牙。

写入后墙钟被设置、`synced` 置真、状态与时间戳持久化。UI 每秒自行重读时间，1 秒内自然刷新。

开机一律回到**未同步**：设备没有 RTC 后备电池，恢复出来的时间戳至少停走了一个关机时长。恢复值仍会被加载（运行期每 5 分钟回写，偏差有上限），仅作粗略显示，未同步期间文字闪烁标记不可信，直到下一次对时。

## 持久化布局

单一 NVS 命名空间 `cyber_clk`：

| 键 | 类型 | 写入时机 | 用途 |
| --- | --- | --- | --- |
| `state` | blob（`time_manager_state_t`） | 同步 / 开机清除 / 时区变更 | synced 标志、同步计数 |
| `tz_offset` | i32 | 时区变更 | 时区秒数（开机读取时键值优先于 blob） |
| `last_unix` | i64 | 同步时，此后同步状态下每 5 分钟 | 粗略恢复值 |
| `bright` | u8 | 亮度变更 | 背光等级（无记录时默认 80） |

flash 磨损说明：5 分钟节奏即每天 288 次写入；未同步状态下的时间从不写入。

## 显示内存与时间预算

- 单 LVGL 屏幕、四个页面容器，v10.1 约 150 个对象。LVGL 池为 64KB（`sdkconfig.defaults`）；v10 曾在 32KB 上耗尽并白屏，因此池大小是构建级不变量——CI 从同一份默认配置构建。
- 全部动效运行在既有的 100ms LVGL 定时器内：心跳相位（lub-dub 双跳）、约 7 秒一次的故障爆发、3 秒换位的故障色条、由"以当前秒为种子的确定性伪随机"驱动的频谱。零新增任务、定时器或内存分配。
- 电池 I2C 每 5 秒在定时器上下文读取一次（数十毫秒，已接受的权衡）；首次读取失败时回落到 50%/3700mV 占位值。

## 失败降级

- NVS 不可用：只打日志；时钟在内存中运行，不做持久化。
- BLE 启动失败：同步页显示 `BT: OFF (USB ONLY)`；USB 对时完全可用。
- 电池读取失败：占位值，UI 其余不受影响。
- 显示/LVGL 初始化失败：带引脚级日志终止启动（见 `main.c` 注释）。

## 已知限制与权衡

- 墨水屏主题按设计禁用残影与故障特效；精简模式隐藏装饰流。
- 电池 I2C 每 5 秒在定时器上下文读取一次（数十毫秒，已接受并注释说明的权衡）。
- 离开同步页时在持有 LVGL 锁的上下文里同步停掉蓝牙——刻意的取舍：接受切页瞬间的一次停顿，换取不需要跨任务拆机状态机。
- 持久化的 state blob 无版本字段；未来结构变更时回落默认值而非迁移。

以下 v10.1 时代的限制已在 v10.3 解决：不可达的 demo 菜单已移除（未被引用的 demo 页连同其拉入的 Wi-Fi 协议栈被链接器裁剪）；NVS 持久化已从 BLE/USB 回调挪到定时器上下文；时区写入增加 ±14 小时最终防线；蓝牙停止失败不再导致服务永久失效。
